01 / Project overview

Turning socioeconomic data into risk categories.

The project used the Child Malnutrition with Socioeconomic Factors dataset, covering 307 observations from 77 countries during 2000–2023. The target was to classify stunting risk into low, medium, and high categories using socioeconomic indicators.

Two classification approaches were compared: Logistic Regression as a baseline model and Random Forest as the stronger final model.

04 / Finished application

Random Forest deployed with Streamlit.

The selected Random Forest model was deployed as a web application. Users can review the dataset, enter socioeconomic indicators, and receive a predicted stunting-risk category with probability visualization. In the example recorded in the report, the application predicted “Risiko Stunting: Tinggi”.
