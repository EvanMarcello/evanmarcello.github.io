01 / Project overview

From lifestyle data to a risk prediction prototype.

The IS388 group project analyzed the Health and Lifestyle Dataset to classify disease risk into low-risk and high-risk categories. The report identifies the dataset as synthetic and documents an end-to-end CRISP-DM workflow.

The initial dataset contained 100,000 records; 80,000 observations were retained for the final analysis. The data was split into training and testing sets using an 80:20 ratio.

02 / Workflow & implementation

What the project delivered.

The report documents data checking and preparation, categorical encoding, numerical scaling, feature engineering, SMOTE for training-set class balancing, Logistic Regression modeling, evaluation, and Streamlit deployment. The model and preprocessing steps were integrated into the web application to generate real-time low-risk or high-risk predictions.

Data & modeling workflow

  • Data preparation and feature engineering
  • Class imbalance handling using SMOTE
  • Logistic Regression training
  • Feature importance interpretation
  • Confusion matrix and classification metrics

Application output

  • Interactive health and lifestyle input form
  • Input summary and validation display
  • Real-time risk classification
  • Prediction probability visualization

The submitted report does not include an individual task-allocation table for this project. The workflow above describes the documented team deliverables, not an unverified personal task assignment.

03 / Actual model performance

Logistic Regression evaluation.

The final report records an accuracy of 83.2%. For the high-risk class, recall reached 81%, meaning the model correctly identified 3,162 of 3,888 high-risk cases in the test results. The macro-average F1-score was 0.79.

The report notes BMI, systolic blood pressure, pulse pressure, diastolic blood pressure, and alcohol consumption among the positive contributors to predicted risk. Sleep duration and daily steps had negative coefficients in this model.
