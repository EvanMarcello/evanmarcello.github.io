01 / Project overview

Structuring publication data for analysis.

The group project models Scopus publication information for Universitas Multimedia Nusantara across 2020–2025. The data warehouse supports analysis of publication output, CiteScore quartiles, faculty and study-program performance, and collaboration patterns.

This is a data warehouse and business-intelligence deliverable, rather than a predictive classification model. Therefore, model accuracy is not the relevant performance measure for this project.

02 / Data architecture

Star schema and ETL workflow.

The Power BI file contains a star-schema model centered on FactPublication, with an author-level table and supporting dimensions for lecturers, study programs, faculties, publication types, venues, years, and CiteScore quartiles.

Data preparation & ETL

  • Power Query transformations
  • Data cleansing and standardization
  • Author-name normalization and deduplication
  • Publication-type and quartile mapping
  • Surrogate-key preparation

Analytics layer

  • DAX measures for publication counts
  • Author counts and Q1–Q4 performance
  • Q1 share calculation
  • Source-to-fact reconciliation and data-quality checks
