01 / Project overview

Making global nutrition data explorable.

The project uses country-level data on child stunting and overweight alongside socioeconomic indicators such as GDP per capita, poverty rate, literacy, fertility rate, and urban population. The work resulted in three interactive dashboards and a data story.
